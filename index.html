    设计原则

    • 极简 — 12 页砍到 7 页；单字段表单降级为弹窗。
    • 少决策 — 截止时间默认当天 24:00，只保留「今天 / 明天 / 后天」三选一。
    • 透明 — 每条作业常驻显示「已完成 x / y」与进度条。
    • 即时 — 点「我已完成」立即写入服务器时间并回报名次。
    • 不重复 — 详情页不重复展示排行榜内容，排名只在排行榜页出现。
    • 边界 — 普通成员看不到发布入口，只能查看与完成。

    已实现的交互

    • 微信授权登录 → 首页
    • 创建班级 / 输入邀请码加入（均为弹窗，不占页面）
    • 发布作业：标题、内容、截止时间（默认当天 24:00）
    • 一键完成（服务端计时 + 名次回显）
    • 实时排行榜 / 逾期分组 / 我的排名
    • 历史作业按日期归档
    • 班级管理：邀请码二维码、改名、移除成员、换码、转让管理员、解散 / 退出
    • 表单校验、空状态、Toast / 确认弹窗 / 底部动作面板
